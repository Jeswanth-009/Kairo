GOOD TO KNOW

Questions before you begin?

Read the README for setup, limitations, and developer instructions.

Do I need AI to use Kairo?

No. Resume import, role matching, editing, PDF export, versions, applications, and backups work without an AI provider. AI adds optional wording suggestions.

Does my data leave my computer?

Kairo keeps your records in a local SQLite database. If you choose a remote AI provider, the role and supporting resume context needed for a suggestion is sent to that provider. The browser demo uses sample data.

Can I install it on macOS or Linux?

The downloadable installer is for Windows 10/11. The core is tested on macOS and Linux, but those platforms do not have an official Kairo installer yet.

Can Kairo read a scanned resume?

Text-based PDF, DOCX, and pasted text are supported. A scanned PDF without a text layer needs OCR elsewhere or manual entry.
