# Kairo Brand Assets (v4)

Source-of-truth for every Kairo logo and marketing visual. The files here are
the originals supplied by the founder (2026-09-22) and should be treated as
read-only references — the app consumes **optimized derivatives** generated by
`scripts/process_brand.py` into `public/brand/`, and the full Tauri icon set in
`src-tauri/icons/` is regenerated from the chosen app icon.

Never hand-edit generated derivatives; re-run the script instead:

```bash
python scripts/process_brand.py
npm run tauri icon scripts/app-icon-source.png   # regenerates src-tauri/icons/*
```
